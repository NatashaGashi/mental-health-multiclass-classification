# mental-health-multiclass-classification
Identifying Mental Health States and Disorders from Online Based Text Data Using Multi-Class Machine Learning Models.Logistic Regression, Random Forest, Decision Tree, and Complement Naive Bayes were used and compared with features such as TF-IDF and Bag-of-Words to classify posts into seven mental health categories.
